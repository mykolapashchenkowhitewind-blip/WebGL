Cornucopia Surface - WebGL Visualization with Normal Mapping

Project Description

This visualization demonstrates a 3D model of a "Cornucopia" surface rendered using WebGL with normal mapping, three textures (diffuse, specular, and normal), and Gram-Schmidt orthogonalization prioritizing the tangent (Variant 23).

The Cornucopia is a special case of a spiral-shaped surface "Shell without vertex". It's a cyclic surface with generatrix circles of variable radius that creates the distinctive horn-like shape.

Mathematical Definition

The Cornucopia surface is defined by the following parametric equations:

Parametric Equations:
x(u,v) = [emu + epucos(v)]cos(u)
y(u,v) = [emu + epucos(v)]sin(u)
z(u,v) = epusin(v)

Where:
- p = 0.15 (parameter p)
- m = 0.1 (parameter m)
- 0 ≤ u ≤ 5π (lengthwise parameter)
- 0 ≤ v ≤ 2π (cross-section parameter)

Texture Transformation

Use keyboard keys to control texture transformations:

  • W/S - Move reference point up/down (v axis)
  • A/D - Move reference point left/right (u axis)
  • Q/E - Decrease/increase scale
  • Z/C - Rotate counter-clockwise/clockwise
  • R - Reset all transformations
Reference Point: (0.50, 0.50)
Scale Factor: 1.00
Rotation: 0.0°

Surface Parameters

Mesh Granularity

U Segments: 80
V Segments: 40

Implementation Details

This implementation includes:

  • Normal Mapping: Per-pixel normal data from normal texture for enhanced surface detail
  • Three Textures: Diffuse texture modulates diffuse lighting, specular texture modulates specular lighting, and normal texture provides per-pixel normals
  • Texture Transformation: Scale and rotate textures around a user-specified point, controllable with keyboard (WASD to move point, QE for scaling, ZC for rotation)
  • Gram-Schmidt Orthogonalization: Tangent space basis is constructed with priority given to the tangent vector (Variant 23)
  • TBN Matrix: Tangent, Bitangent, and Normal vectors transform normals from tangent space to view space
  • Phong Shading: Realistic lighting with ambient, diffuse, and specular components
  • Rotating Light Source: A moving light that circles around the model
  • Triangle Mesh: The surface is rendered with filled triangles using VBO with indices
  • Adjustable Granularity: U and V segment sliders allow controlling the mesh density
